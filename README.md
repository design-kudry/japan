# Travelapp

Планировщик путешествий: маршрут по дням, конструктор с картой и шторкой, каталог мест, расходы и заметки.

## Запуск

Требуется Node.js 22+ и npm.

```sh
npm ci
npm run build
npx serve dist
```

Откройте адрес, который покажет сервер. Основные маршруты: `/#japan`, `/#new`, `/#trip/<id>`.

## Состав репозитория

- `index.html`, `js/`, `css/` — действующий сервис.
- `image/` — только используемые SVG-иконки; фото загружаются из внешних источников.
- `places/cities/` — справочники стран и городов для выбора поездки.
- `scripts/` — сборка и обновление справочника городов.
- `tests/` — проверки логики сервиса.
- `docs/` — спецификация, авторские подборки и источники данных.

Старые автономные страницы и прототипы удалены. Для восстановления прежних файлов доступна история Git.
