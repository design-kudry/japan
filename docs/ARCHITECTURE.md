# Архитектура текущей версии

Срез 17.11.2026. Поведение продукта: [SERVICE_SPEC.md](SERVICE_SPEC.md). Хранение: [DATA.md](DATA.md). Данные мест: [PLACES_PIPELINE.md](PLACES_PIPELINE.md).

## Исполнение

Статическое веб-приложение: React 18, Gravity UI UIKit/Date Components, Inter; сборка esbuild. Основная SPA работает в index.html, маршрутизация — hash. Свой сервер приложения, серверная БД поездок и пользовательская авторизация не реализованы. Ограничение доступа хостинга не является системой аккаунтов планировщика.

## Поток данных мест

Готовая библиотека отображается сразу. Сетевые кандидаты города/области/поиска сопоставляются и фильтруются; принятые записи пополняют общую библиотеку. Обогащение медиа и метаданных выполняется отдельно. Авторский текст не должен заменяться слабым внешним описанием. Некоторые вызовы и кеши остаются специализированными: это не одна серверная БД с транзакциями.

## Карты и шторка

EditorMap используется во всех картах, включая компактные превью маршрута: MapLibre/OpenFreeMap Positron, при отсутствии WebGL — Leaflet/OSM с общим стилем. Превью создаются через IntersectionObserver только рядом с экраном; компактный режим отключает жесты карты и кнопки масштаба. Цвет дня сохраняется между превью и редактором. Маркеры хранятся по placeId и обновляются отдельно от инициализации подложки. Географический якорь — центр круга 36 px. Подпись не смещает координату; declutter управляет видимостью точек и текста.

PlacesMap разделяет каталог и routeMode. В routeMode discovery не запускается. RouteExplorer содержит full/half/peek/browse и управляет положением шторки через Pointer Events. Верхний offset 68 px и резерв футера используются одновременно в JS и CSS; менять их независимо нельзя.

## Состояние и сохранение

Основной JSON поездок и записи расходов/заметок — localStorage. Билеты — IndexedDB. Черновики форм, фильтры, открытые окна, библиотека и часть кешей живут в памяти. Нет облачной репликации, общего backend-состояния и гарантий синхронизации нескольких вкладок.

Транспортные секреты не должны появляться в клиенте. TRANSPORT_API_BASE нельзя включать, пока не существует сервер с соответствующими endpoint.

## Сборка и размещение

`npm ci` → `npm run build` → dist/. scripts/build-gravity.mjs копирует статические страницы/данные и собирает React, CSS, шрифты, MapLibre worker. Hash-навигация не требует серверного fallback для каждой поездки. Абсолютные пути worker и справочников городов требуют настройки при размещении в подпапке.

Старый planner-sw.js удаляет прежний кеш и снимает регистрацию Service Worker. Offline-first режим не реализован. Устаревшие HTML-страницы, их модули и разовые скрипты удалены. Единственная точка входа — index.html; редактор cities/<id> остаётся частью trips.js. Сборка очищает dist и копирует только ресурсы действующего приложения.
