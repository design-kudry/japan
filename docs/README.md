# Документация Travelapp

Актуальный срез: **17 ноября 2026**. Основная спецификация описывает фактический код, отдельно отмечая ограничения и неподключённые функции.

| Документ | Назначение |
| --- | --- |
| [SERVICE_SPEC.md](SERVICE_SPEC.md) | Полная функциональная спецификация всех основных экранов, сценариев, правил и ограничений |
| [FLOWS.md](FLOWS.md) | Краткие последовательности пользовательских действий |
| [ADD_PLACE_FLOW.md](ADD_PLACE_FLOW.md) | Оба входа добавления места, фильтры и назначение дня |
| [TRANSPORT.md](TRANSPORT.md) | Booking/Segment, ручной ввод, билеты и будущие API |
| [PLACES_PIPELINE.md](PLACES_PIPELINE.md) | Общая библиотека, загрузка города/области/поиска и качество данных |
| [place-meta.md](place-meta.md) | Форматирование текста, цены/часов и фотографий |
| [DATA.md](DATA.md) | Схемы, ключи хранения, удаление и переносимость |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Модули, исполнение, карты и сборка |

Исторические [AUDIT.md](AUDIT.md) и [BACKLOG.md](BACKLOG.md) содержат наблюдения/предложения, а не подтверждение реализованных возможностей. Документы-подборки, JSON в sources/ и старые pending-файлы — материалы импорта; актуальный состав каталога определяется кодом, а не статусом старого списка ожидания.

При расхождении с более старой записью сначала сверяйте SERVICE_SPEC.md и соответствующий модуль. Не дописывайте новые взаимоисключающие правила в конец устаревшего документа: обновляйте действующий раздел.
