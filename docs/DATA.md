# Данные и публикация

Пользовательские записи хранятся в localStorage текущего браузера:

- `japan-travel-trips-v1` — поездки, места, переезды, избранное, изменения маршрута.
- `japan-active-trip` — последняя активная поездка.
- `travel-notes-v1:<route>` — заметки.
- `trip-expenses:<route>` — расходы.

Удаление созданной поездки удаляет её из массива поездок; для встроенной Японии устанавливается флаг `japanDeleted`. Отдельные ключи расходов и заметок при этом сейчас не очищаются. Очистка данных браузера уничтожает локальные записи. GitHub содержит код и исходные материалы, а не поездки пользователя из браузера.

Сборка: `npm ci && npm run build`. Любой статический хостинг может обслуживать `dist/`; используется hash-маршрутизация, серверный fallback для маршрутов не требуется. Для размещения в подпапке нужно адаптировать абсолютный путь `/js/maplibre-worker.mjs`. `.openai/hosting.json` содержит конфигурацию существующего Sites-проекта, для нового проекта его идентификатор следует заменить.

Секретов и ключей для карты нет. Геокодирование городов — Open-Meteo, векторная подложка — OpenFreeMap, резервная — OpenStreetMap. Сохраняйте атрибуцию поставщиков карты.
