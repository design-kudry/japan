# Данные, сохранение и размещение

Срез 17.11.2026. Полная спецификация моделей и сценариев: [SERVICE_SPEC.md](SERVICE_SPEC.md), разделы 10–14.

## Хранилища

| Место | Ключ / объект | Данные |
| --- | --- | --- |
| localStorage | japan-travel-trips-v1 | Поездки и локальные изменения встроенной Японии |
| localStorage | japan-active-trip | Последняя активная поездка |
| localStorage | travel-notes-v1:<routeHref> | Массив заметок |
| localStorage | trip-expenses:<routeHref> | Массив расходов |
| localStorage | places-v2:<страна\|город> | Кеш городской подборки и время записи; читается при возрасте до 24 часов |
| IndexedDB | travel-ticket-files / files | Файлы билетов по ID |
| Память вкладки | records, кеши запросов, React state | Загруженная библиотека, фильтры, черновики и состояние UI |

Основной JSON содержит trips[], japanTransfers[], japanPlaces[], japanWishlist[], japanDeleted, routeEdits и bookings. Поля могут создаваться лениво. Встроенная Япония берёт основу из DAYS/STAYS и применяет локальные изменения. Booking встроенной Японии хранится в корне основного JSON; Booking пользовательской поездки — внутри Trip.

## Сущности

- Trip: id, start/end либо dateMode=days + dayCount, cities[], places[], wishlist[], routeEdits, transfers[] старого формата, bookings[].
- Place: идентичность, имя/описания, координаты и география, тип, часы/цена/длительность, фото, ссылки и лицензии. Не все поля обязательны во всех источниках.
- Booking: id, tripId, supplier, pnr, passengers, price|null, currency, sourceFile|null, segments[], createdAt, updatedAt.
- Segment: id, kind, carrier, number, from/to {name, code, timeZone}, departureUtc, arrivalUtc, status, seat, travelClass, terminal, gate; assignedDay для бездатного маршрута. Черновик содержит локальные даты/время.
- sourceFile: id, name, type, size. Байты находятся отдельно в IndexedDB.
- Expense: id, date, name, amount, category, payer, split[].
- Note: id, title, text.

У места приоритетен id, затем Wikidata; резервный идентификатор — name|lat|lng. routeEdits[день] хранит переопределённый упорядоченный список мест дня. Длительности транспорта вычисляются из UTC, не хранятся как отдельный источник истины.

## Жизненный цикл

Назначение места переносит его между днями, исключая повтор в выбранном дне. Избранное ведётся отдельно. Изменение маршрута сохраняется сразу; заметки и черновик Booking — только явным подтверждением.

При ошибках записи основной JSON/массив откатывается там, где это предусмотрено обработчиком. Нельзя считать запись успешной только потому, что изменился экран. При ошибке сохранения метаданных нового билета выполняется очистка созданного в этой попытке файла.

Удаление Booking пытается удалить его файл. Удаление всей поездки исключает Trip из массива либо ставит japanDeleted; отдельные ключи расходов/заметок и файлы не удаляются каскадно. Встроенная поездка не имеет кнопки восстановления. Интерфейс экспорта/импорта всей поездки отсутствует.

## Передача и переносимость

localStorage/IndexedDB привязаны к браузеру и origin. Другой профиль, устройство или хост не получает эти данные автоматически. «Поделиться» передаёт URL без содержимого Trip; GitHub содержит исходный код и подготовленные каталоги, а не сохранения пользователя из браузера.

Очистка данных браузера уничтожает локальные записи. Смена домена/протокола создаёт другой контекст хранения. Файл нельзя восстановить по sourceFile.name без его байтов в IndexedDB.

## Размещение

`npm ci && npm run build`; обслуживается dist/. Маршруты используют hash. В .openai/hosting.json указан существующий Sites-проект; при создании другого проекта этот ID нельзя считать новым. При размещении в подпапке нужно адаптировать абсолютные URL MapLibre worker, справочников городов и ресурсов, которые используют путь от корня.

Ключей картографических/транспортных провайдеров для работающих публичных источников не требуется. Это не означает наличие серверных транспортных интеграций. Атрибуция OSM, OpenFreeMap, GeoNames и источников медиа сохраняется.
