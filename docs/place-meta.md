## Компактные карточки и галерея — 13.11.2026

- Маленькая карточка: короткое описание, максимум 3 строки. Метаданные одной строкой: «≈ ¥800 · 9:00–16:00». Первый основной диапазон часов без сезонов, дат, «ориентировочно», последнего входа и иных пояснений. Переполнение — многоточие, без переноса. Исходные часы остаются в данных.
- Полная карточка: полное пользовательское описание без автоматического сокращения. Абзацы по 1–2 предложения, удобный межстрочный интервал. Краткие цена/часы без повторяющихся блоков; отдельно длительность посещения.
- Нажатие на фото открывает полноэкранную галерею. Закрытие — крестик/Escape; переключение — кнопки, стрелки клавиатуры или свайп. Счётчик только при нескольких реальных фото.
- Дополнительные снимки берутся из статьи соответствующего места и проверяются через Commons; сохраняются автор, лицензия и ссылка. Никаких вымышленных кадров или повторов для заполнения галереи. Если источник даёт одно фото, показываем одно.

## Кварталы и памятники — 13.11.2026

По правилу продукта кварталы и памятники показывают только «Круглосуточно», без суммы и без «Бесплатно». Типы quarter/neighbourhood/suburb/monument/memorial и явный outdoorAlwaysOpen используют одно форматирование во всей системе. Это правило не распространяется на музейные здания и закрытые комплексы.

# Короткий формат цены и часов — 13.11.2026

Общее форматирование во всех карточках: «≈ £55 · 10:00–18:00». Перед числовой ценой — ≈, без «взрослым», «билет», «экскурсия» и прочих условий. Подтверждённый бесплатный вход — «Бесплатно». Неизвестную стоимость не выдумываем. Часы — диапазон без «Ежедневно»; различающиеся часы по дням сохраняются. Круглосуточный режим — только из источника или подтверждённого доступа. Неизвестные часы — «Уточнить часы». Исходные данные и ссылка на источник сохраняются.

Этот раздел заменяет прежние правила отображения ниже.

# Цены и время работы мест

## Согласованное правило — 12.11.2026

Единое правило для карточек места во всей системе: каталог, сохранённые места, маршрут, конструктор, мини-карточки на карте и полная карточка. Этот раздел заменяет прежние правила «Бесплатно», «Платно» и «—». Форматирование применяется через общие `placeMeta`, `placePriceLabel` и `placeRouteMeta` в интерфейсе.

| Ситуация | Отображение |
| --- | --- |
| Подтверждённый уличный объект со свободным круглосуточным доступом: памятник, площадь, улица | Только `Круглосуточно`, без цены |
| Место с режимом работы: музей, храм, парк с воротами | Реальные часы работы; цена, если вход платный и сумма известна |
| Вход бесплатный | Цену скрываем; слово `Бесплатно` не выводим |
| Стоимость известна | Только сумма и валюта, например `£55` или `¥1,500–2,500`; без «взрослый», «экскурсия», «от» и других приписок |
| Платный вход, сумма неизвестна | Цену скрываем; `Платно` и выдуманную сумму не выводим |
| Часы неизвестны | `Уточнить часы` со ссылкой на подтверждённый официальный сайт |
| Часы и официальный сайт неизвестны | `Уточнить часы` обычным текстом; ссылку не придумываем |

Если известны оба значения, компактная строка — `цена · часы`. Если цена скрыта, показываем только часы или `Уточнить часы`. Не заменяем метаданные описанием места.

Категория сама по себе не доказывает круглосуточный или бесплатный доступ. Для парков, храмов, огороженных территорий и объектов с ограничениями используем реальные сведения. Отсутствие цены или часов у источника не означает свободный вход или режим 24/7.

Стоимость должна относиться к выбранному посещению: не подставляем цену экскурсии вместо наружного осмотра. Уточнения и условия источника сохраняются в данных, но не добавляются к строке цены. Несовместимые тарифы не объединяем в выдуманную сумму.

## Реализация и источники

Форматирование: `js/place-meta.js`; загрузка: `js/place-enrichment.js`. Источники — OSM element API и Overpass (`opening_hours`, `fee`, `charge`), Wikivoyage, Wikidata и проверенные официальные страницы. Исходные поля сохраняются отдельно от их отображения. Сведения и ссылки должны относиться к тому же объекту.

## Description quality

`js/russian.js` → `polishDescription` / `placeDescription`:

1. Drop thin Wikidata stubs («город в …», disambiguation, заготовки).
2. Prefer a Wikipedia sentence with visit signal (музей, храм, смотровая, …).
3. If nothing useful remains — category + city + short “why go” hint (not invented facts).

Enrichment stores only polished text (`usefulPlaceDesc`). Hand-written Japan `data.js` blurbs stay as-is.

## Wikivoyage и скорость загрузки

Дополнительный бесплатный источник — публичный MediaWiki API en.wikivoyage.org (без ключа). Поиск `insource:Q…`, извлечение `hours` и `price` только из listing с точным совпадением Wikidata ID. Цена и часы публикуются сразу по готовности, независимо от фотографий. Запрос ограничен двенадцатью секундами; результаты кешируются в памяти. В карточке показывается ссылка на Wikivoyage и лицензия CC BY-SA. Полнота и актуальность зависят от сообщества; отсутствие сведений не означает бесплатный или круглосуточный доступ. В OSM конкретный `charge` приоритетнее общего `fee=yes`.

Закрытый поиск использует тот же Gravity TextInput, что открытый. У иконки 16×16 одинаковый левый отступ 12 px и правый 2 px.

## Дополнительные источники и идентичность

Photon не передаёт Wikidata ID. После получения точных OSM tags метаданные повторно запрашиваются с найденным ID. Неполный кеш (нет цены) допускает повторную загрузку. Дополнительно читается Wikidata P2555: единственная недепрекейтнутая цена без даты окончания, с известной валютой. Для неоднозначных тарифов значение не выбирается автоматически.

`extra-place-meta.js` содержит также две проверенные 12.11.2026 записи официальных сайтов: Big Ben (экскурсия, не наружный осмотр) и National Gallery. Совпадение обязательно по названию и координатам; это ограниченный справочник, не глобальный API. Источник виден в карточке. Проверка актуальности этих записей пока ручная.

Проверки отображения: `node --test tests/place-meta.test.mjs`. Компактная карточка ведёт в полную карточку; ссылка «Уточнить часы» доступна в полной карточке, если известен официальный сайт. Автоматическое определение свободного доступа по категории не применяется.
