# Отображение метаданных и фотографий места

Актуально на 17.11.2026. Заменяет прежние противоречащие правила «не показывать Бесплатно» и «скрыть На посещение». Полная спецификация: [SERVICE_SPEC.md](SERVICE_SPEC.md), раздел 8.

## Формат цены и часов

Общие функции — placePriceLabel, placeHoursLabel, placeMeta и placeRouteMeta в js/place-meta.js. Исходные strings не меняются ради короткого отображения.

| Случай | Текущее отображение |
| --- | --- |
| Единственная распознаваемая числовая цена | ≈ + сумма и валюта |
| Строка бесплатного входа | Бесплатно |
| Платно без суммы или несколько несовместимых тарифов | Сумма скрыта |
| Распознаваемый интервал часов | Краткий интервал |
| Неизвестные/нераспознаваемые часы | Уточнить часы |
| Круглосуточный режим | Круглосуточно |

Компактная строка: цена · часы. Она не переносится; переполнение обрезается. placeRouteMeta использует первый распознанный диапазон времени, без сезона, условий входа и тарифных пояснений. Длительность посещения не смешивается с часами работы.

Текущее исключение в коде: quarter/neighbourhood/neighborhood/suburb/monument/memorial и outdoorAlwaysOpen показываются как «Круглосуточно» без цены. Это правило классификации, не подтверждение реального доступа внешним источником.

В полном описании есть отдельные заголовки «Время работы», «Билет» при наличии цены и «На посещение» при наличии duration. Источники/лицензии выводятся при наличии полей. Кликабельный официальный сайт под текстом «Уточнить часы» не гарантируется текущей разметкой каждой карточки.

## Текст

Краткое и полное описание начинается с заглавной буквы; полное — по абзацам. Авторское описание приоритетно. Маленькая карточка обрезает текст стилями; полное описание разбивается на читаемые абзацы по одному-двум предложениям. Текст категорийной заглушки не следует считать проверенным рассказом гида.

## Медиа

Карточка резервирует место под изображение; при загрузке — скелетон, после ошибки — статичная заглушка. Фото мини-карточки карты/конструктора — 166 px; белое перекрытие 20 px. В полной карточке перекрытие 24 px.

Точки 8 px с промежутками 4 px находятся на 9 px выше белой части. При одном фото точек нет. В маленьком каталоге нет ни точек, ни стрелок. В остальных карточках нет стрелок поверх обложки; переключение доступно свайпом/точками/клавиатурой при нескольких снимках.

Фото полной карточки открывает отдельный PhotoViewer. В нём есть видимый крестик, стрелки, свайп/перетаскивание, клавиши ←/→, точки и Escape. Закрытие возвращает только из галереи в описание; индекс синхронизирован.

Дополнительные снимки проверяются по ссылке, лицензии и эвристике соответствия. Источник может вернуть один снимок или ни одного. Не создаются вымышленные дополнительные кадры. Авторство и лицензия сохраняются с каждым файлом.
